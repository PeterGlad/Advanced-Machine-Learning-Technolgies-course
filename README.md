# Advanced Machine Learning Technologies — Course Materials

Teaching materials for the **Advanced Machine Learning Technologies (AMLT)** course at ITMO University.

The repository contains lecture slides, Jupyter notebooks, practical assignments, datasets, exam questions, and the course project assignment, organized by topic.

## Course contents

| Section | Topics | Materials available in this archive |
|---|---|---|
| [01 — Interpretable Machine Learning](01_Interpretable_Machine_Learning/) | Model interpretability, permutation importance, partial dependence, SHAP, LIME | Lecture PDFs, notebook, Task 1 |
| [02 — Reinforcement Learning](02_Reinforcement_Learning/) | Reinforcement learning, multi-armed bandits, epsilon-greedy strategy | Lecture PDF, notebook |
| [03 — Time Series Analysis and Forecasting](03_Time_Series_Analysis_and_Forecasting/) | Time-series properties, classical methods, SARIMA, forecasting metrics, multivariate series and causality | Lecture PDF, ARIMA and LSTM notebooks, dataset, Assignment 2 |
| [04 — Attention Models and Transformers](04_Attention_Models_and_Transformers/) | Seq2Seq, RNN/LSTM, attention, Transformers, Vision Transformers | Lecture PDF |
| [05 — Generative Models](05_Generative_Models/) | Generative models and VAEs | Lecture PDF, Task 3 |
| [07 — Diffusion Models](07_Diffusion_Models/) | Diffusion models, text-to-image generation, Stable Diffusion and related architectures | Lecture PDF |
| [08 — Modern Image Processing and IQA](08_Modern_Image_Processing_and_IQA/) | Camera pipelines, denoising, demosaicing, super-resolution, HDR, synthetic datasets, image quality assessment | Lecture PDFs, notebook, Assignment 4 |
| [09 — TinyML and Model Deployment](09_TinyML_and_Model_Deployment/) | TinyML, inference constraints, model optimization, LiteRT and ExecuTorch | Lecture PDF |
| [Course Information](Course_Information/) | Exam questions and course project | Exam questions PDF, course project assignment PDF |

## Repository structure

Each topic has its own directory. Course-level assessment documents are stored separately in `Course_Information/`.

The section numbers follow the identifiers present in the supplied course materials. **Section 06 was not present as a separate archive in the uploaded package**, so the original numbering has not been renumbered.

## Notes

- Original lecture files, notebooks, assignments, and datasets are preserved as supplied, except for removal of macOS metadata files and extraction of nested ZIP archives into the corresponding topic folders.
- Notebook code and execution paths have **not** been adapted for local execution.
- Some lecture slide titles use lecture numbers that differ from the archive/topic identifiers; original filenames and slide contents are retained.
- Please check redistribution permissions for all lecture slides and third-party datasets before sharing this repository publicly.
